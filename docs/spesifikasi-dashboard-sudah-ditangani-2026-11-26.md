# Spesifikasi dashboard — pilihan "Sudah saya tangani"

Versi: 2026-11-26

Setiap kartu di bagian Menunggu Bapak punya radio **Sudah saya tangani**. Radio ini selalu ada, di posisi terakhir sebelum **Keputusan lain**, baik pilihan kartu berasal dari teks pertanyaan maupun tidak.

Memilih radio itu lalu menekan Simpan menulis persis `Sudah ditangani Abduh` di kolom Keputusan. Waktu WIB tetap `diputuskan via dashboard, …`. Komentar tetap masuk ke Tanggapan saya. Kartu yang sudah terisi hilang dari daftar terbuka, sama seperti keputusan lain.

Bila daftar pilihan sudah memuat `Sudah saya tangani`, `Sudah ditangani`, atau `Sudah ditangani Abduh`, radio itu tidak digandakan. Pilihan tetap yang lain, termasuk `Sudah saya tangani sendiri`, tidak berubah.
